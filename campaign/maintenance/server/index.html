유지보수

교회 홈페이지 서버관리

시스템 엔지니어가 교회 홈페이지 서버를 전담해 관리·운영합니다. 사전점검부터 모니터링, 보안, 백업과 복구까지 서버 일은 교회사랑넷이 맡습니다.

서버관리란

교회사랑넷 서버관리는 IDC센터의 웹서버를 시스템 엔지니어가 점검·모니터링하고 용량과 장애를 관리하는 서비스입니다.

SERVER

서버관리 포함 범위

서버운영관리는 네 갈래로 이뤄집니다.

  1. 사전점검·기술지원생길 수 있는 문제를 미리 점검해 예방하고, 1:1 전담 엔지니어가 기술을 지원합니다.
  2. 모니터링365일 24시간 모니터링 관제시스템을 가동하고, 네트워크를 실시간 점검합니다.
  3. 보안물리적·논리적 방화벽과 바이러스 방역, 정기적인 보안패치와 소프트웨어 업그레이드를 합니다.
  4. 리포팅·컨설팅서버와 운영시스템 전반을 안내하고, 서비스 특성에 맞춰 컨설팅합니다.

SERVICE DETAIL

서비스 상세 내용

기술지원
서버 OS·솔루션 설치, 실시간 기술지원과 장애복구, OS·시스템 업그레이드, 하드웨어·노후장비 교체, 시스템 컨설팅
모니터링
상시 모니터링 시스템 사용, 서버 문제 발생 시 실시간 문자메시지 자동 알림, 엔지니어 상시 모니터링 점검
보안
방화벽(Fire wall)·웹방화벽 구축, 보안 업데이트와 포트 최적화, 바이러스 백신 업데이트와 방역
백업·복구
주요 데이터 상시 백업(1일·1주·1개월), 장애 발생 시 복구서비스

IDC센터에서 운영합니다

교회사랑넷의 서버운영관리 서비스는 IDC센터(인터넷데이터센터)에서 운영합니다.

  • 기가급 인터넷 백본(자체 보안기능 탑재)
  • 백본 이중화 구성
  • 통합감시시스템 운영(전기, UPS, 누수, 온습도, 소방, 공조 등)
  • 통합감시용 모니터링 시스템 운영
  • 상시 기술인력 대기
  • 서버실 보안시스템

서버 용량과 비용

교회사랑넷 홈페이지는 웹서버 10GB가 기본이고, 유지보수 플랜에 따라 서버 용량이 정해집니다. 유튜브 설교는 주소만 연결하므로 서버 용량을 쓰지 않습니다.

서버 용량 추가나 접속 장애는 관리자 화면의 CCS로 요청하시거나 평일 09:30~17:00에 1661-9106으로 연락해 주세요.

자주 묻는 질문

교회 홈페이지 서버 용량은 얼마나 주나요?

웹서버 10GB가 기본으로 제공됩니다. 월 유지보수 A. 자체관리 플랜은 10GB, B·C·D 플랜은 20GB입니다. 더 필요하면 웹서버 용량을 10GB 추가할 때마다 월 11,000원입니다.

설교 동영상 때문에 용량이 부족하지 않을까요?

유튜브에 올린 설교 영상은 주소만 입력해 홈페이지 설교 전용게시판에서 보여 주므로 웹서버 용량을 쓰지 않습니다. 동영상 설교방송서버를 따로 쓰는 경우 10GB 추가 시 월 11,000원입니다.

서버에 문제가 생기면 어떻게 알 수 있나요?

상시 모니터링 시스템이 서버를 살피고, 서버 문제가 생기면 엔지니어에게 실시간 문자메시지로 자동 알림이 갑니다. 365일 24시간 관제하며 장애가 나면 복구서비스를 지원합니다.

서버는 어디에서 운영하나요?

교회사랑넷 서버운영관리 서비스는 IDC센터(인터넷데이터센터)에서 운영합니다. 기가급 인터넷 백본과 백본 이중화, 전기·UPS·누수·온습도·소방·공조 통합감시, 서버실 보안시스템을 갖추고 기술인력이 상시 대기합니다.
