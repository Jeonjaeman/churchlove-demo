교회 홈페이지 제작 비용

교회 홈페이지 비용은 처음 한 번 내는 구축비와 매월 내는 유지보수비로 나뉩니다. 제작 방식별 금액을 교회사랑넷 안내 그대로 모았습니다.

구축비 보기 월 유지보수 보기

교회 홈페이지 제작 비용이란

교회사랑넷 교회 홈페이지 제작 비용은 제작 방식별 1회 구축비와 A~D 월 유지보수비, 필요할 때 내는 추가 작업비로 이뤄집니다.

구축비

BUILD

제작 방식별 구축비 (1회)

모두 PC·태블릿·모바일 반응형이며 웹서버 10GB·유튜브 설교 무료 연결·CMS 사용교육 1회가 기본입니다.

게시판은 모든 방식에서 무제한이고 설교게시판은 유튜브와 무료로 연동됩니다. 콘텐츠 디자인은 교회에서 직접 추가하면 무료입니다. AI 하이브리드 출시 이벤트 종료일은 따로 안내되어 있지 않습니다.

MAINTENANCE

월 유지보수 요금 (매월)

홈페이지를 연 뒤 매월 내는 관리비입니다. 주문제작형을 포함한 모든 제작 방식이 같은 A~D 플랜을 씁니다. B·C·D 는 A 의 서비스에 디자인 작업 지원이 더해집니다.

  • A. 자체관리

    29,700원 / 월

    디자인선택·편집·주문형 안내 표기 할인 22,000원/월 · AI 하이브리드는 29,700원 필수

    • 교회가 직접 고치는 수정·관리 시스템
    • 디자인 샘플팩(메인·콘텐츠·팝업 1,500여 종)
    • 메뉴 등록·삭제, 게시판·사진앨범 직접 추가
    • 게시판 무한 추가(무료), 웹진·e주보 무료
    • 사용방법 매뉴얼(동영상·설명서), Q&A 문의·답변

    서버용량 10GB

  • B. 스탠다드

    66,000원 / 월

    A 서비스 기본 제공 +

    • 메인전환이미지 1건, 팝업 3건 이하 (대신 팝업 5건 가능)
    • 간단한 텍스트 수정 작업
    • SSL 보안, 이중 백업, 복구 서비스
    • 전문 디자이너 이미지 제작 지원(AI 보조), 1:1 전담 커뮤니케이터 전화 상담, 필요 시 원격 지원

    서버용량 20GB

  • C. 프리미엄

    99,000원 / 월

    A 서비스 기본 제공 +

    • 메인전환이미지 2건, 팝업 5건 이하 (대신 팝업 8건 가능)
    • 간단한 텍스트 수정 작업
    • SSL 보안, 이중 백업, 복구 서비스
    • 전문 디자이너 이미지 제작 지원(AI 보조), 1:1 전담 커뮤니케이터

    서버용량 20GB

  • D. 스페셜

    121,000원 / 월

    A 서비스 기본 제공 +

    • 메인전환이미지 3건, 팝업 7건 이하 (대신 팝업 10건 가능)
    • 간단한 텍스트 수정 작업
    • SSL 보안, 이중 백업, 복구 서비스
    • 전문 디자이너 이미지 제작 지원(AI 보조), 1:1 전담 커뮤니케이터

    서버용량 20GB

자주 묻는 질문

교회 홈페이지 제작 비용은 얼마인가요?

구축비는 제작 방식에 따라 AI 하이브리드 0원(출시 이벤트, 정가 110,000원), 디자인선택형 198,000원부터 550,000원까지, 디자인편집형 1,100,000원부터, 주문제작형 별도협의(견적)입니다.

매달 내는 유지보수비는 얼마인가요?

A. 자체관리 29,700원, B. 스탠다드 66,000원, C. 프리미엄 99,000원, D. 스페셜 121,000원입니다. A는 서버 10GB, B·C·D는 20GB이며 메인전환이미지·팝업 작업 지원이 늘어납니다.

유지보수 계약 외에 수정을 맡기면 비용이 드나요?

텍스트 페이지 내용수정 11,000원/1page~, 팝업창 1건 33,000원~, 메인상단 대형이미지 제작 55,000원~, 연 업데이트 작업요청 110,000원/1건~입니다. 수정 분량에 따라 비용이 추가될 수 있습니다.

서버 용량이 모자라면 어떻게 하나요?

웹서버와 동영상 설교방송서버 모두 10GB 추가 시 월 11,000원으로 늘릴 수 있습니다.

요금은 어디로 입금하나요?

구축비·유지보수비 입금 계좌와 현금영수증 신청은 고객센터의 입금 계좌 안내에 있습니다. 요금 문의는 1661-9106 내선 670~671 총무팀으로 해 주세요.
