주요기능

교회 홈페이지 CMS 관리시스템

글자 몇 개를 바꾸려고 제작 업체에 연락하고 기다리고 계신가요? 교회사랑넷 CMS(Church-love net Management System)로 교회 홈페이지를 직접 관리하세요.

CMS 관리시스템이란

교회사랑넷 CMS는 홈페이지 내용 수정, 메뉴 변경, 게시판 추가 같은 유지보수를 교회가 직접 하는 관리자 시스템입니다.

이럴 때 필요합니다

  • 홈페이지 글자 몇 개를 고치려고 제작 업체에 부탁하고 기다릴 때
  • 앨범 게시판이 몇 개 더 필요한데 비용이 걱정될 때
  • 한번 정한 메뉴를 바꾸고 싶을 때
  • 사역자가 바뀌어 섬기는 이 소개와 매년 연혁을 고쳐야 할 때
  • 팝업창을 교회에서 바로 올리고 내리고 싶을 때

FEATURES

CMS 관리시스템의 주요 메뉴

회원관리
홈페이지 회원 관리와 승인, 레벨 부여, 가입폼 관리, 회원에게 메일 보내기를 합니다.
관리자관리
관리자를 여러 명 등록하고 관리자별로 관리 권한을 줍니다.
메뉴관리
메뉴 추가, 메뉴명 수정, 메뉴 이동을 교회에서 언제든 합니다.
페이지관리
홈페이지 내용을 원 관리자가 직접 바꿉니다.
게시판 관리
추가 버튼 하나로 게시판과 사진앨범을 만듭니다. 추가할 때마다 비용이 들지 않습니다.
연혁관리
년도별 교회 연혁을 교회에서 자유롭게 등록·수정·삭제합니다.
섬기는 이 관리
목사님과 섬기는 분들의 사진과 정보를 등록·수정·삭제합니다.
팝업&배너 관리
이미지를 첨부하듯 올리면 홈페이지에 팝업창이 자동으로 등록됩니다.
통계관리
일별·월별·요일별 방문자 통계와 페이지별 방문횟수를 그래프로 봅니다.

CMS 쓰는 순서

  1. CMS 받기 — 홈페이지 구축이 끝나면 사용법 교육과 함께 CMS를 드립니다.
  2. 관리자 로그인 — 교회사랑넷 관리자 로그인 화면으로 들어갑니다.
  3. 메인페이지 확인 — 회원가입 현황, 최근 게시물, 접속통계, 업무요청 처리현황을 한번에 봅니다.
  4. 필요한 메뉴에서 수정 — 메뉴관리·페이지관리·게시판 관리·팝업&배너 관리에서 직접 고칩니다.
  5. 어려운 작업은 요청 — 직접 하기 어려운 수정은 CCS 유지보수 요청으로 담당자에게 맡깁니다.

CMS 실제 화면

CMS 메인페이지의 10가지 정보와 관리 메뉴 화면입니다.

  1. 관리자페이지 기본정보기본정보, 서버 사용량, 담당자정보 확인
  2. 도메인 정보 확인사용 중인 도메인의 만료일을 따로 검색하지 않아도 확인
  3. 교회사랑넷 소식 알림꼭 읽어야 할 공지를 배너로 확인
  4. CCS 유지보수 현황확인유지보수 요청과 처리현황을 한눈에 확인
  5. 최근 게시물 확인모든 게시판의 최근 글을 모아 보기
  6. 최근 댓글 확인모든 게시판의 댓글을 모아 보기
  7. 최근 등록 사진최근 올라온 사진을 모아 보기
  8. 회원데이터 확인전체 회원가입 인원과 신규 가입회원 정보
  9. 기능업데이트 공지정기 기능 업데이트를 실시간으로 확인
  10. 교회사랑넷 공지교회사랑넷 소식을 공지사항으로 확인

자주 묻는 질문

CMS는 언제 받을 수 있나요?

CMS는 홈페이지 구축이 끝나면 사용법 교육과 함께 드리는 홈페이지 관리시스템입니다. 관리자 로그인 후 바로 쓸 수 있습니다.

게시판이나 사진앨범을 더 만들면 비용이 드나요?

들지 않습니다. CMS에서 추가 버튼 하나로 게시판과 사진앨범을 만들 수 있고, 교회에서 필요한 만큼 만들어 쓸 수 있습니다.

메뉴 이름이나 순서도 교회에서 바꿀 수 있나요?

네. 메뉴관리에서 메뉴 추가, 메뉴명 수정, 메뉴 이동을 교회가 직접 합니다.

관리자를 여러 명 둘 수 있나요?

네. CMS는 관리자를 여러 명 등록할 수 있고, 관리자마다 관리 권한을 따로 줄 수 있습니다.

팝업창은 어떻게 올리나요?

팝업&배너 관리에서 사진이나 이미지를 자료실에 첨부하듯 올리면 홈페이지에 팝업창이 자동으로 등록됩니다.
