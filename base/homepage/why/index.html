관리 시스템

교회사랑넷 홈페이지를 고르는 이유

전문 디자이너가 만든 디자인에, 교회가 직접 쓰는 관리 시스템과 1:1 유지보수를 더했습니다. 메뉴·회원·팝업·일정을 관리자 화면에서 직접 다룹니다.

교회사랑넷 홈페이지 관리 시스템이란

교회사랑넷 홈페이지 관리 시스템은 메뉴·회원·관리자·일정·팝업·통계를 교회가 관리자 화면에서 직접 다루는 프로그램입니다.

3 IN 1 SYSTEM

구축 + CMS + CCS 를 하나로

홈페이지 구축
템플릿 디자인과 맞춤형 디자인 가운데 교회에 맞는 방식으로 구축합니다.
CMS (Church-love net Management System)
내용 수정, 메뉴명 수정·추가, 게시판·사진앨범 추가, 팝업·배너 관리를 교회에서 직접 합니다.
CCS 유지보수 (Church-love net Customer System)
교회에서 고치기 어려운 사항은 CCS로 요청하면 디자인 담당자와 프로그램 담당자에게 실시간으로 전달되고, 처리 현황과 결과를 확인합니다.

REASONS

관리자 화면에서 직접 하는 9가지

  1. 전문 디자이너가 만드는 디자인

    홈페이지 디자인은 교회의 얼굴입니다. 전문 디자이너가 교회에 맞는 디자인을 만듭니다. 디자인은 제작 사례에서 비교해 보세요.

  2. 메뉴 자동 생성·삭제

    원하는 메뉴를 언제든 만들거나 지우고, 메뉴 이름을 고치고, 위치를 자유롭게 옮깁니다.

  3. 그룹·레벨 회원관리와 메일 발송

    가입 회원을 레벨별·그룹(구역)별로 나눠 관리하고, 전체 또는 그룹을 골라 교회소식 알림·새신자 메일을 보냅니다.

  4. 관리자 권한 부여

    최고 관리자가 여러 관리자를 등록하고 메뉴별 관리 권한을 나눠 효율적으로 관리합니다.

  5. 행사·일정 달력

    관리자는 교회 행사와 일정을 쉽게 등록하고, 교인은 달력에서 편하게 확인합니다.

  6. 팝업창·배너 관리

    이미지만 첨부하면 팝업창과 배너가 자동으로 등록되고, 쉽게 올리고 내립니다.

  7. 방문자 통계 분석

    홈페이지 방문자 통계와 페이지별 접속 현황을 관리자 화면에서 봅니다.

  8. 실시간 유지보수 CCS

    직접 고치기 어려운 부분은 CCS로 요청하면 1:1 매칭 담당자가 처리하고, 처리 상황을 실시간으로 확인합니다.

  9. 공개된 요금

    제작 방식별 구축비와 월 유지보수 요금을 공개합니다. 요금표와 디자인을 직접 비교하고 결정하세요.

자주 묻는 질문

메뉴는 교회에서 직접 만들 수 있나요?

네. 관리자 화면에서 언제든지 메뉴를 만들거나 지우고, 메뉴 이름을 고치고, 메뉴 위치를 옮길 수 있습니다.

교인을 구역별로 나눠 메일을 보낼 수 있나요?

가입 회원을 레벨별·그룹(구역)별로 나눠 관리하고, 전체 또는 특정 그룹을 검색해 이메일을 보낼 수 있습니다. 교회소식 알림이나 새신자 메일에 씁니다.

관리자를 여러 명 둘 수 있나요?

최고 관리자가 여러 관리자를 등록하고 메뉴별 관리 권한을 나눠 줄 수 있습니다.

직접 고치기 어려운 부분은 어떻게 하나요?

관리자 화면의 CCS로 요청하면 실시간으로 접수되어 1:1 매칭 담당자가 처리하고, 처리 상황을 실시간으로 확인할 수 있습니다.
