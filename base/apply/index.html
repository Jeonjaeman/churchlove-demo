교회 홈페이지 구축 신청·견적 신청

구축 신청, 견적 신청, 해외 홈페이지 신청은 교회사랑넷 신청 페이지에서 접수합니다. 신청 전에 준비할 것과 최근 접수 현황을 확인하세요.

교회사랑넷 신청 페이지로 이동 견적 신청하기

구축 신청이란

교회사랑넷 구축 신청은 상담·견적을 받은 교회가 신청서를 내고 구축비를 입금해 홈페이지 제작을 시작하는 단계입니다.

APPLY

신청 방법 4가지

버튼을 누르면 같은 창에서 교회사랑넷 신청 페이지로 이동합니다.

  • 홈페이지 구축 신청

    견적서를 받았다면 견적 번호(견적서 교회명 바로 아래)를 입력해 견적 내용으로 자동 신청하고, 바꿀 부분만 고칩니다. 견적서 없이 원하는 항목만 골라 신청할 수도 있습니다.

    교회사랑넷 신청 페이지로 이동

  • 견적 신청

    구축지역(국내·해외), 교회명, 신청자 연락처, 현재 홈페이지와 참고 홈페이지, 요청사항을 남기면 담당자가 확인 뒤 견적서를 보냅니다.

    견적 신청하기

  • 구축 문의(상담 신청)

    교회명·담당자·연락처·이메일을 남기면 담당자에게 온라인으로 전달되고 확인 뒤 답변을 드립니다. 근무시간에 전화하면 더 빨리 상담합니다.

    교회사랑넷 신청 페이지로 이동

  • 해외 홈페이지 신청

    북미 등 해외 한인교회는 전화(+82-43-272-0903)나 이메일로 상담한 뒤 해외 신청서를 씁니다. 신청 뒤 인보이스를 보내 드립니다. 해외 한인교회 홈페이지 제작 안내

    교회사랑넷 신청 페이지로 이동

신청 전에 준비할 것

  • 제작 방식과 예산 — 제작 방식 4가지 비교, 교회 홈페이지 제작 비용
  • 원하는 월 유지보수 플랜(A~D) — 월 유지보수 요금
  • 필요한 메뉴 구성과 기능 목록
  • 사진 자료(교회 전경·행사·부서)와 내용 자료(인사말·예배시간·기관 소개)
  • 참고하고 싶은 홈페이지 주소 — 교회 홈페이지 제작 사례

신청서를 낸 뒤 구축비를 입금하면 준비사항과 기본 메뉴 구성안을 받습니다. 자세한 단계는 구축 진행 순서에 있습니다. 상담은 평일 09:30~17:00(토·일·공휴일 휴무) 전화 1661-9106.

자주 묻는 질문

견적서를 받은 뒤 신청하면 무엇이 편한가요?

구축신청 페이지에서 견적서의 견적 번호를 입력하면 견적서 내용으로 자동 신청됩니다. 바꿀 부분만 수정해 신청하면 됩니다. 견적 번호는 견적서의 교회명 바로 아래에 있습니다.

견적서 없이도 신청할 수 있나요?

네. 견적서를 받지 않아도 원하는 신청 항목만 골라 신청할 수 있습니다.

상담을 받으면 꼭 신청해야 하나요?

아닙니다. 상담을 받고 가격과 기능을 비교한 뒤 결정하셔도 됩니다. 상담은 평일 09:30~17:00 전화 1661-9106으로 할 수 있습니다.

신청서는 어디에서 쓰나요?

구축신청·견적신청·해외 홈페이지 신청 양식은 교회사랑넷 신청 페이지(실사이트)에서 작성합니다. 이 쪽의 버튼을 누르면 같은 창에서 해당 신청 페이지로 이동합니다.
