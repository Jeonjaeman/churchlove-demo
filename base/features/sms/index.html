주요기능

교회 SMS 문자발송

긴급한 교회 소식, 모임 안내, 문자 심방까지. 휴대폰보다 쉽고 편하게 교인에게 문자를 보내세요.

SMS 문자발송이란

교회사랑넷 SMS 문자발송은 홈페이지에서 교회 회원과 그룹을 골라 단체 문자를 보내고 결과를 확인하는 문자 시스템입니다.

이럴 때 필요합니다

  • 긴급한 교회 소식을 한 번에 알려야 할 때
  • 모임 안내를 그룹별로 보내야 할 때
  • 문자로 심방하며 교인을 챙기고 싶을 때
  • 정해 둔 날짜·시간에 안내 문자를 보내고 싶을 때

FEATURES

SMS 문자발송의 특징

적립금으로 누구나
적립금을 충전해 교회 회원 누구나 씁니다. 교회 관리자는 충전한 적립금을 회원(목회자)에게 나눠 줄 수 있습니다.
단문·장문 발송
단문(90Byte)과 장문 문자메시지를 보냅니다.
예약 전송
원하는 날짜와 시간에 문자를 예약해 보냅니다.
그룹·단체 발송
교회 회원과 그룹을 지정해 단체 문자를 보냅니다.
발송내역 확인
전송 결과로 문자가 정상 발송됐는지 확인합니다.
이모티콘
이모티콘, 특수문자, 조합문자로 문자를 꾸밉니다.

문자 보내는 순서

  1. 적립금 충전 — 관리메뉴의 충전하기에서 발송 비용을 충전합니다.
  2. 문자 입력 — 문자입력창에 내용을 씁니다. 90Byte가 넘으면 장문으로 발송됩니다.
  3. 받는 사람 고르기 — 연락처를 직접 입력하거나(20명까지) 주소록에서 회원 검색·그룹선택으로 고릅니다.
  4. 바로 또는 예약 전송 — 바로 보내거나 원하는 날짜·시간을 정해 예약합니다.
  5. 결과 확인 — 관리메뉴의 예약확인·전송결과에서 발송 상태를 확인합니다.

SCREEN

문자전송 실제 화면

화면의 번호 01~06은 아래 설명과 같습니다.

  1. 문자입력창90Byte까지 입력, 넘으면 장문으로 발송
  2. 전화번호 입력창직접 입력 시 20명까지 동시 발송, 주소록 선택 시 등록 인원 모두에게 발송
  3. 예약전송원하는 날짜·시간에 전송
  4. 관리메뉴예약확인 · 전송결과 · 주소록관리(등록·수정·삭제) · 충전하기
  5. 주소록등록된 회원 검색과 그룹선택으로 받는 사람 선택
  6. 이모티콘이모티콘, 특수문자, 조합문자 제공

문자 발송 비용

SMS 문자메시지 발송 비용(건당)
구분글자 수가격
단문 SMS90Byte20원/건
장문 LMS2,000Byte50원/건

적립금을 충전해 쓰는 방식입니다. 홈페이지 구축비·유지보수 요금은 교회 홈페이지 제작 비용에서 확인하세요.

자주 묻는 질문

문자 한 건에 얼마인가요?

단문 SMS(90Byte)는 20원/건, 장문 LMS(2,000Byte)는 50원/건입니다. 적립금을 충전해 씁니다.

한 번에 몇 명에게 보낼 수 있나요?

받는 사람 연락처를 직접 입력하면 20명까지 동시에 보냅니다. 주소록을 선택하면 주소록에 등록된 인원 모두에게 한 번에 보낼 수 있습니다.

담임목사님 말고 다른 교역자도 쓸 수 있나요?

네. 교회 관리자가 적립금을 충전한 뒤 회원(목회자)에게 나눠 줄 수 있어 교회 회원 누구나 쓸 수 있습니다.

문자가 제대로 갔는지 확인할 수 있나요?

관리메뉴의 전송결과에서 문자가 정상적으로 발송됐는지 확인하고, 예약확인에서 예약 전송이 제대로 잡혔는지 확인합니다.

90Byte를 넘기면 어떻게 되나요?

문자입력창은 90Byte까지 단문으로 보내고, 90Byte가 넘어가면 장문으로 발송됩니다.
