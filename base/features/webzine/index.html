주요기능

교회 웹진·모바일 주보

교회 주보와 소식지, 책자를 홈페이지에서 카탈로그처럼 발행하세요. 책장을 넘기듯 보고 메일로도 보냅니다.

교회 웹진이란

교회사랑넷 웹진은 교회 주보·소식지·책자를 홈페이지에서 카탈로그처럼 발행해 보고 이메일로 보내는 기능입니다.

이럴 때 필요합니다

  • 매주 나오는 주보를 홈페이지와 스마트폰에서도 보여 주고 싶을 때
  • 교회 소식지나 책자를 온라인으로 발행하고 싶을 때
  • 주보를 교인에게 메일로 보내고 싶을 때

FEATURES

웹진 시스템의 특징

무한 발행
매주 또는 호수별로 웹진을 발행합니다. 생성 개수에 제한이 없습니다.
책장넘기기
책장을 넘기듯 보고, 원하는 페이지로 바로 이동합니다.
확대보기
화면을 확대하고, 이미지를 누르면 크게 봅니다. 다른 웹진으로 옮겨 볼 수 있습니다.
이메일 발송
발행한 웹진을 이메일로 보냅니다.
웹진 이름
웹진 이름을 교회가 마음대로 정합니다.
쉬운 생성·관리
웹진을 쉽게 만들고 관리해 주보나 소식지로 씁니다.

웹진 발행 순서

  1. 웹진 만들기 — 웹진 이름을 정하고 주보·소식지로 쓸 웹진을 만듭니다.
  2. 호수별 발행 — 매주 또는 호수별로 새 호를 발행합니다.
  3. 홈페이지에서 보기 — 교인이 책장을 넘기며 보고 확대해 읽습니다.
  4. 이메일 발송 — 필요하면 발행한 웹진을 이메일로 보냅니다.

자주 묻는 질문

웹진은 몇 호까지 만들 수 있나요?

매주 또는 호수별로 웹진을 발행할 수 있고 생성 개수에 제한이 없습니다.

웹진을 쓰는 데 비용이 드나요?

교회사랑넷 월 유지보수 플랜(A. 자체관리 29,700원/월부터)에는 웹진·e주보 무료 제공이 포함되어 있습니다. 플랜별 내용은 유지보수 쪽에서 확인하세요.

주보를 교인에게 메일로 보낼 수 있나요?

네. 발행한 웹진을 이메일로 보내는 기능이 있습니다.

웹진은 어떻게 보이나요?

카탈로그처럼 책장을 넘기며 보고, 원하는 페이지로 바로 이동하거나 화면과 이미지를 확대해 봅니다. 다른 웹진으로 옮겨 볼 수도 있습니다.
