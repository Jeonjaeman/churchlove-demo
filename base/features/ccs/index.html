주요기능

CCS 실시간 유지보수 요청 시스템

전화로 요청한 수정이 처리되고 있는지 몰라 다시 전화하고 계신가요? CCS(Church-love net Customer System)로 요청하고 처리 상황을 확인하세요.

CCS란

교회사랑넷 CCS는 교회와 교회사랑넷을 잇는 실시간 커뮤니티이자 1:1 담당자 유지보수 요청 시스템입니다.

이럴 때 필요합니다

  • 홈페이지 수정을 위해 몇 번씩 전화해도 통화가 되지 않을 때
  • 전화로 요청한 유지보수가 처리되고 있는지 확인할 방법이 없을 때
  • 요청 내용이 담당자에게 제대로 전달되지 않아 수정이 늦어질 때

FEATURES

CCS의 특징

홈페이지 오픈과 함께 셋팅
홈페이지를 열 때 CCS가 셋팅되고 접속 아이디와 비밀번호가 부여됩니다.
1:1 매칭 담당자
CCS에 로그인하면 교회를 맡은 담당자 정보를 확인합니다.
실시간 접수
요청은 매칭된 담당자의 컴퓨터 화면에 실시간으로 전달되어 접수됩니다.
처리 단계 안내
접수확인, 작업진행중, 처리완료 단계로 처리상황을 알려 드립니다.
예상 완료일자 안내
작업량이 많거나 시간이 지체되면 예상 완료일자를 알려 드립니다.
커뮤니티
유지보수 요청과 함께 교회와 교회사랑넷이 소통하는 커뮤니티로 씁니다.

유지보수 요청 순서

  1. CCS 로그인 — 홈페이지 오픈 때 받은 아이디와 비밀번호로 로그인하고 1:1 매칭 담당자를 확인합니다.
  2. 요청 작성 — 고칠 내용이나 문제를 적어 유지보수를 요청합니다.
  3. 실시간 접수 — 요청이 담당자 컴퓨터 화면에 바로 전달되어 접수됩니다.
  4. 처리 상황 확인 — 접수확인 → 작업진행중 → 처리완료 단계를 CCS에서 확인합니다.

CCS 유지보수 요청과 처리현황은 CMS 관리시스템 메인페이지에서도 한눈에 볼 수 있습니다.

자주 묻는 질문

CCS는 따로 신청해야 하나요?

교회사랑넷 홈페이지 오픈과 함께 CCS가 셋팅되고 접속 아이디와 비밀번호가 부여됩니다.

요청한 작업이 어디까지 진행됐는지 알 수 있나요?

네. 담당자가 접수확인, 작업진행중, 처리완료 단계로 처리상황을 알려 드립니다. CCS에 로그인하면 요청과 처리상태를 확인할 수 있습니다.

작업이 오래 걸리면 어떻게 되나요?

유지보수 작업량이 많거나 시간이 지체될 때는 예상 완료일자를 알려 드립니다.

요청은 누가 받나요?

CCS로 요청하면 교회에 1:1로 매칭된 교회사랑넷 담당자의 컴퓨터 화면에 실시간으로 전달되어 접수됩니다. CCS 로그인 후 담당자 정보를 확인할 수 있습니다.
